# C & Python Exercises

Standalone practice problems written while learning C and Python, kept as a record of the exercises rather than as coursework.

**Personal project (not coursework)**

## Contents

| Folder | Contents |
|---|---|
| `c-lab/` | Nine introductory C exercises — pseudo-random numbers, loops, arrays and control flow |
| `c-scratch/` | Scratch tests: an OpenMP experiment, `complex.h`, and assorted small programs |
| `c-projects/` | Dynamic array allocation, sorting, a blueprint parser, and a Windows-95 keygen toy |
| `python-exercises/` | A circle-overlap geometry exercise with input/output fixtures, and a script that plots values read from a data file |

## Running

```bash
gcc c-lab/1.c -o lab1 && ./lab1
python python-exercises/solution.py < python-exercises/f4.txt
```
